# 通知内容模板使用指南

LunaTV 的通知系统支持**通知内容模板化**：在"编辑通知渠道"时可以自定义通知的内容样式，通过变量把动态数据（剧集数量、剧集条目、检查时间等）填入你编排的文本中。

不配置模板时，通知使用默认样式，与历史版本完全一致。

## 📍 在哪里编辑模板

1. 进入 **设置 → 通知设置**（仅管理员可见）
2. 在"通知渠道"列表点击某个渠道的 **编辑** 按钮
3. 弹窗中的 **通知内容模板** 区块即为模板编辑器（仅当该渠道订阅的事件支持模板变量时显示）
4. 编辑完成后点击 **保存渠道**

编辑器包含：

| 元素         | 说明                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| 模板输入框   | 直接编辑模板文本（等宽字体）                                              |
| 变量标签     | 点击在光标处插入该变量；列表类变量（如 `newUpdates`）会插入**完整段落块** |
| 恢复默认模板 | 把输入框重置为该事件的默认模板                                            |
| 实时预览     | 用示例数据渲染当前模板，所见即所得                                        |

> 💡 **发送测试通知**（渠道卡片上的"测试"按钮）在所有渠道统一支持模板预览：渠道订阅了追更事件时，测试通知会用追更样例数据按当前渠道模板渲染；点"测试"即可直接看到模板效果。未订阅带样例事件的渠道，测试通知保持通用测试文本（正式发送仍按模板渲染）。

## 🧩 模板语法

### 1. 变量插值 `{{变量名}}`

```
{{title}}

共有 {{newCount}} 部新更新
```

渲染时 `{{title}}`、`{{newCount}}` 会被替换为实际值。**未定义的变量替换为空字符串**，不会报错。

允许变量名两侧带空格：`{{ title }}` 与 `{{title}}` 等价。

### 2. 条件区块 `{{#变量}}...{{/变量}}`

```
{{#newUpdates}}

🆕 新更新（{{newCount}}）

{{newUpdates}}
{{/newUpdates}}
```

- 变量**有值** → 保留区块内部内容（标记本身不输出）
- 变量**为空** → 整块删除（含区块内的所有文字）

这个语法用于"某类更新为空时整段不显示"的场景：例如某次检查只有已更新、没有新更新，那么 `{{#newUpdates}}...{{/newUpdates}}` 包住的整个"🆕 新更新"段落都会自动隐藏。

### 3. 空行折叠与修剪

渲染结果中 3 个及以上连续换行会折叠为 2 个（即最多保留一个空行），首尾空白会被去掉。因此删除变量/空区块后残留的多余空行会被自动清理，不需要手动处理。

## 📋 追更通知可用变量（`watching.update_found`）

| 变量               | 说明                                 | 示例值                                                                 |
| ------------------ | ------------------------------------ | ---------------------------------------------------------------------- |
| `{{title}}`        | 通知标题                             | `更新提醒`                                                             |
| `{{newCount}}`     | 新更新的剧集数量                     | `1`                                                                    |
| `{{newUpdates}}`   | 新更新的剧集条目串（条目间空行分隔） | `海贼王（如意资源）\n12 → 14 集（+2）`                                 |
| `{{updatedCount}}` | 已更新的剧集数量                     | `2`                                                                    |
| `{{updated}}`      | 已更新的剧集条目串                   | `死神（电影天堂）\n5 → 8 集（+3）\n\n九门（极速资源）\n6 → 8 集（+2）` |
| `{{displayTime}}`  | 检查时间                             | `2026-08-02 12:30:01`                                                  |

> 剧集条目的格式为：第一行 `剧名（资源站名）`（无来源信息时仅剧名），第二行 `起始集数 → 最新集数 集（+增量）`。

### 默认模板（默认样式）

```
{{title}}
{{#newUpdates}}

🆕 新更新（{{newCount}}）

{{newUpdates}}
{{/newUpdates}}
{{#updated}}

✅ 已更新（{{updatedCount}}）

{{updated}}
{{/updated}}
```

渲染效果（两类更新都存在时）：

```
更新提醒

🆕 新更新（1）

海贼王（如意资源）
12 → 14 集（+2）

✅ 已更新（2）

死神（电影天堂）
5 → 8 集（+3）

九门（极速资源）
6 → 8 集（+2）
```

## ✏️ 自定义示例

### 示例 1：修改段落标题措辞与 emoji

```
{{title}}
{{#newUpdates}}

🔥 新番更新（{{newCount}}）

{{newUpdates}}
{{/newUpdates}}
{{#updated}}

📺 追更进展（{{updatedCount}}）

{{updated}}
{{/updated}}
```

### 示例 2：极简列表（无段落标题）

```
{{title}}（{{displayTime}}）
{{#newUpdates}}

新：{{newUpdates}}
{{/newUpdates}}
{{#updated}}

更：{{updated}}
{{/updated}}
```

### 示例 3：只要新更新、不要已更新

```
{{title}}

🆕 有 {{newCount}} 部新更新

{{newUpdates}}
```

（`{{newUpdates}}` 变量为空时，整段同样会渲染为空内容，配合空行折叠不会留多余空行。）

## 📌 注意事项

- 模板长度上限 **2000 字符**，超长保存会被拒绝。
- 模板保存在**每个渠道**的配置里 —— 同一事件在不同渠道可以使用不同模板。
- 模板对**所有渠道**生效（站内通知、企业微信、Telegram、Bark、Webhook、邮件、PushPlus、Server酱等）。
- 留空/恢复默认模板并保存 = 使用该事件的默认样式。
- 模板只影响**通知正文**，通知标题不受模板控制。
- 企业微信渠道对默认样式的追更通知会渲染为富文本 markdown；自定义模板的内容按普通 markdown 发送（`### 标题 + 正文 + 时间` 格式）。
- 条件区块**不支持嵌套**。

## 🔌 技术说明（开发者）

- 模板引擎位于 `src/lib/notification/notification-template.ts`（域中立），渲染规则与本文一致。
- 追更事件的变量定义在 `src/lib/watching-update-notification-builder.ts` 中通过 `notificationTemplateVariableRegistry` 注册。
- 后续其他事件（如更新失败、系统错误）如需支持模板，可按同样模式注册变量解析器，前端编辑弹窗会自动展示。
